# Specs (general)

Product and feature specifications that are **not** tied to the Superpowers
plan/spec workflow.

| Location | Use for |
|----------|---------|
| `docs/specs/` (here) | Standing product specs, RFCs, cross-cutting designs |
| `docs/superpowers/specs/` | Design specs paired with Superpowers implementation plans |
| `docs/architecture/` | ADRs, service contracts, project strategy |
| `docs/research/` | Scratch comparisons, investigations (gitignored) |

Add new general-purpose specs as markdown files in this directory.
